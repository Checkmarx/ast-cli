What is MCP Server?
MCP (Model Context Protocol) is an open standard enabling AI assistants and agents to connect to external data sources and tools in real time. An MCP server exposes a set of "tools" — structured functions an AI agent can call to retrieve data or perform actions.

An MCP server is a bridge that lets AI talk to external tools and real-world data.
How it works
What is Checkmarx Public MCP Server?
Enables developer and security teams to query their Checkmarx One platform using natural language through AI chat interfaces. Instead of navigating the web UI or writing API calls, ask questions like "show me all critical SAST findings" or "which projects haven't been scanned in two weeks" and get immediate, accurate answers.
How it works
Reads code and manifest files directly
Triggers SAST, SCA & KICS scans
Returns results in plain English inside IDE / CLI
Works in VS Code, JetBrains, Cursor & CLI

Known Constraints — V1
Limitations
Transparently documenting what's not yet supported in the current release
🔒
Secret Detection not implemented
Secret / credentials scanning is not available in V1. Planned for a future release.
🤖
Model-dependent output format
Different AI models (GPT, Claude Sonnet, etc.) may produce varying output structure or formatting. Results are not guaranteed to be identical across all models.
📁
Local directory scan runs server-side
The cx_scan_directory_local tool scans a directory from the server where it is deployed — not from the client machine. Ensure the directory is accessible from the server.
